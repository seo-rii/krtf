# 검색·구조화 생성·독립 문단 평가 최종 결과

후속 큐의 **4,096회가 모두 완료됐다.** API 오류·누락은 0건이며, Qwen pack 자유
생성에는 형식 오류 12건이 별도로 있다. 2026-10-18 03:41:59 KST에 추론이 끝났고,
03:42:58 KST에 자동 수집·원본 검증·재채점·집계 푸시가 종료 코드 0으로 끝났다.
이 분석에서도 네 단계의 봉인된 원본과 공개 집계를 다시 대조해 일치함을 확인했다.

**BM25는 이 새 표본에서 두 모델의 답변 정답 일치를 늘렸다. JSON 스키마 제약은
반복해서 나타난 Qwen의 pack 형식 오류를 없애면서 양성 정답 수를 유지했다.**
KTRF pack의 추가 이득은 여전히 소수 문항이고, 독립 AI 문단 평가의 규모도 운영
위험을 검증하기에는 부족하다. 두 개선은 현재 평가 코드에서 비교한 것이며,
운영 검색기나 API의 기본 디코딩 설정에 자동 반영한 변경은 아니다.

## 1. 새 기사에서의 검색 비교

이전 생성·준비 pool·근거 평가·독립 문단 평가의 기사 parent와 내용 해시를 제외한
새 기사 128개를 썼다. 양성은 SPAN 40개·YES/NO 8개, 무응답은 80개다.
이전 생성 평가의 64/64 구성과 다르므로 점수를 같은 표본처럼 합치지 않는다.
최초 표집 목표의 부족과 생성 전 구성 변경은 [고정 계획](../FOLLOWUP_PLAN_20261018.md)에 보존했다.

표의 정답은 양성 48문항의 normalized EM이다. 무응답 null은 별도 80문항이다.

| 검색 조건 | Gemma 12B 정답 | Qwen 27B 정답 | Gold 근거 보존 | 올바른 null: Gemma / Qwen |
|---|---:|---:|---:|---:|
| 기존 lexical | 22/48 (45.8%) | 25/48 (52.1%) | 33/48 | 73/80 / 73/80 |
| BM25 | **25/48 (52.1%)** | **29/48 (60.4%)** | 35/48 | 73/80 / 73/80 |
| 인접 구간 | 19/48 (39.6%) | 23/48 (47.9%) | 22/48 | 71/80 / 70/80 |
| Oracle | 35/48 (72.9%) | 37/48 (77.1%) | 48/48 | 72/80 / 73/80 |

BM25는 lexical보다 Gemma 정답 3개·Qwen 정답 4개가 늘었다. 양성·음성 전체의
동일 질문 비교에서는 Gemma helpful 5·harmful 2, Qwen helpful 8·harmful 4다.
평균 점수 개선과 함께 악화된 개별 문항도 남아 있다. 인접 구간을 우선 넣는
현재 방식은 두 모델에서 모두 더 낮았다.

원문 상한은 두 실제 토크나이저 각각 1,536토큰·3,000문자·3구간으로 같지만,
BM25의 실제 입력 토큰은 lexical보다 **Gemma 22.2%, Qwen 22.5% 많았다.**
Gemma 합계는 71,685→87,624토큰, Qwen은 66,124→80,994토큰이다.
같은 상한에서의 비교이며 같은 실제 소비 비용에서의 개선이라고 주장하지 않는다.

BM25 정답 중 선택 구간에 gold 위치가 없는 결과는 Gemma 2건·Qwen 3건이다.
Lexical에서는 각각 0건·1건이었다. gold 위치가 남은 정답만 세면 Gemma는
22→23개, Qwen은 24→26개다. 정답 일치 증가 전체를 근거 회수 개선으로 읽지 않는다.

Oracle은 원래 정답 문단 전체 하나를 제공하는 **gold 기반 진단 조건**이다.
무응답에서는 lexical과 동일한 프롬프트를 사용한다. 배포할 수 있는 검색기가
아니며 일반 검색 순위에 포함하지 않는다. 정답 문단이 있어도 EM은 Gemma 35/48,
Qwen 37/48에 그쳐, 검색 이후의 답변·추출·문자열 일치 문제도 남아 있다.
이 평가는 이미 알려진 기사 안에서 구간을 고른 것이며 전체 문서 집합에서
정답 기사를 찾는 성능은 측정하지 않았다.

## 2. 같은 질문의 3회 반복과 JSON 스키마 제약

기존 128질문을 재사용했다. 양성 64개·무응답 64개이고, 같은 원문·프롬프트·
온도 0·seed 0으로 조건별 3회 실행했다. 반복은 독립 질문을 늘리지 않는다.
아래는 각 반복의 분모로 표시하며, 세 반복에서 같은 값은 하나로 적었다.

| 모델 | 문맥 / 생성 방식 | 양성 정답 / 64 | 올바른 null / 64 | 형식 오류 / 128 |
|---|---|---:|---:|---:|
| Gemma | 검색 / 자유 또는 스키마 | 매회 32 | 매회 61 | 매회 0 |
| Gemma | Pack / 자유 | 33, 33, 32 | 매회 62 | 매회 0 |
| Gemma | Pack / 스키마 | 매회 33 | 매회 62 | 매회 0 |
| Qwen | 검색 / 자유 또는 스키마 | 매회 31 | 매회 63 | 매회 0 |
| Qwen | Pack / 자유 | 매회 33 | 매회 59 | **매회 4** |
| Qwen | Pack / 스키마 | 매회 33 | 매회 63 | **매회 0** |

Qwen 자유 pack의 형식 오류는 같은 무응답 질문 4개에서 세 번씩 반복돼
**총 12/384건**이었다. 스키마 제약은 이 오류를 0건으로 줄이고 올바른 null을
59/64→63/64로 회복했다. 양성 정답 33/64는 그대로였다. 단순히 잘못된 JSON을
사후 수정한 것이 아니라, 별도 스키마 조건에서 다시 생성한 결과다. 모든 HTTP
요청이 성공했고 스키마 미지원 시 자유 생성으로 대체하는 경로도 사용하지 않았다.

스키마 조건의 검색→pack은 Gemma에서 양성 정답 1개·올바른 null 1개 증가,
Qwen에서 양성 정답 2개 증가·null 동일이었다. Qwen 추가 정답은 모두 YES/NO로
4/8→6/8이며 SPAN은 27/56으로 같았다. 작은 관측 개선을 일반적인 KTRF 우위로
확대하지 않는다. Pack은 포맷과 정책을 함께 바꾼 개입이다.

Gemma 자유 pack은 1문항의 답변이 반복 사이에서 달랐다. 정규화된 답이 세 번
모두 같은 그룹은 127/128이고, 스키마 pack에서는 128/128이었다. 검색/pack의
프롬프트가 같은 비교 쌍 300개 중에도 Gemma 답변 불일치가 1건 있었다.
검색과 음성 oracle의 동일 프롬프트 비교에서도 Gemma 불일치 1건이 있었다.
따라서 온도 0의 단회 결과나 한 문항 차이를 모두 개입 효과로 단정하지 않는다.
Qwen 자유 pack의 반복 일치 통계는 형식 오류가 있는 4개 그룹을 제외하므로
유효 그룹 124개에서의 일치를 전체 128개 성공으로 해석하지 않는다.

## 3. 독립 AI 문단 gold

Resolver 실행 전에 원천에서 선택한 서로 다른 기사 24개의 문단 하나씩을 두 AI가
각각 주석하고 4문단의 이견을 조정했다. 원본 주석·조정·원문 offset·내용 해시를
봉인한 뒤 평가했다. 원문 전체 기사나 사람이 검증한 gold는 아니다.

등록 대상 LINK는 4개, NIL은 46개, 무언급 문단은 14개였다. fast와 commit 모두
등록 대상 4건을 정확히 확정했고 NIL 오확정은 없었다. 그러나 개발·보정·test
각 8문단 중 test의 LINK는 2개, 보정의 LINK는 0개다. 보정 학습을 수행하지 않고
`calibration_fit_status=INSUFFICIENT_DATA`, `coverage_valid=false`로 남겼다.
모든 관측 full-surface가 SAME이어서 파생 의미 guard도 검증하지 못했다.
오확정 0건을 운영 오류 한도 충족이나 무검토 자동 실행의 근거로 사용하지 않는다.

## 검증·적용 범위

추론 revision `492120c`의 one-server 전체 테스트는 1,502개 통과했다.
원본 요청·응답·채점·동결 envelope 해시와 manifest seal, CPU 증빙,
실행 환경을 검증했고, 이 분석에서도 4,096개 응답을 다시 채점해 공개 결과 및
두 모델 비교와 일치함을 확인했다. 원문과 개별 답변은 공개하지 않는다.

근접 기사 중복·Wikipedia와 사전학습 중복은 배제하지 못한다. 모델 계열과 크기가
함께 바뀌고 공유 서버에서 실행했으므로 크기나 지연만의 인과 효과를 주장하지
않는다. 생성 문자열 EM·문자 F1은 프로젝트 진단이며 공식 TyDi 점수가 아니다.

이번 결과는 BM25와 스키마 제약을 다음 적용 후보로 유지할 근거를 준다. 운영
통합은 별도 변경이며, BM25+pack+스키마를 결합한 최종 구성의 성능은 아직
측정하지 않았다. 서로 다른 실험의 이득을 더해 그 구성의 점수를 예측하지 않는다.
