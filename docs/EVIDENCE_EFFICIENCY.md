# 짧은 근거 참조와 선택적 검사 비교

2026-10-21. [동일 후보·근거 ID 비교 512회](../reports/evidence_queue_20261021/RESULTS.md)는
완료했다. 서버가 근거 위치를 복원하면 정상 연결을 회복했지만, 단순 선택보다
요청 p95가 Gemma 약 4.8→23.0초, Qwen 약 7.1→35.7초로 늘었다. 아래는
그 결과를 바탕으로 비용과 새로운 사례에서의 품질을 함께 확인하는 다음 계약이다.
현재는 준비 단계이며 결과는 `reports/efficiency_queue_20261021/`에 별도로 게시한다.

## 비교 대상

| 조건 | 제공 사실·응답 방식 | 확인하려는 효과 |
|---|---|---|
| `plain_matched` | 같은 실제 후보를 단순 용어표로 제공, 간결한 ID 제안 | 낮은 비용의 기준선 |
| `evidence_long` | 기존 형식의 후보와 긴 요청·entity·근거 참조 | 새 자료에서 기존 방법 재확인 |
| `evidence_short` | 같은 원문·정의·속성·근거에 짧은 요청별 참조와 응답 필드 | 참조·응답 길이 감소 |
| `evidence_compact` | 짧은 참조에 중복 키를 줄인 복원 가능한 사실 표 | 정보 손실 없는 입력 축소 |
| `selective_compact` | 같은 짧은 형식, 고정된 원문 규칙으로 추가 검사 여부 결정 | 불필요한 검사 비용 회수 |

원문 전체, entity 정의, 예외·적용 범위는 자르지 않는다. compact 표를 복원하면
기존 후보·속성·근거 사실과 일치하는지 준비 및 요청 검증 때 확인한다. 근거 ID는
실제 요청의 문서·snapshot·발생 위치와 서버 매핑에 묶인다. 짧은 별칭을 다른
요청·entity·근거에 쓰면 거절한다. 실험의 결정적 짧은 별칭은 라이브러리의
[운영용 무작위 참조](COMPACT_EXECUTION.md)와 구분한다.

모든 조건은 실제 resolver가 생성한 후보만 사용하고 같은 production occurrence
검증기로 승인 여부를 판정한다. 모호한 후보를 모델에 보여줄 수 있지만 의미 제안이
실행 권한으로 승격되지는 않는다. 실제 동작은 실행하지 않는다.

## 검사 경로 결정

선택적 검사는 모델 출력 전에 원문·요청 위치·실제 후보·resolver 관찰만 사용한다.
고유 발생, 단일 확정 후보, 네 적용 속성의 명시적이고 유일한 일치, 충돌·인용·부정
징후 부재 등 고정 조건을 만족하면 추가 근거 출력을 생략한다. 나머지는 근거
검사로 보낸다. 정답 라벨·자료 층 이름·모델 신뢰도·모델 간 일치는 사용하지 않는다.

이 규칙은 비용 경로 선택용 휴리스틱이다. 네 문자열이 원문에 있다는 사실만으로
해당 발생에 대한 의미 함의가 증명되지는 않는다. 생략 경로에서도 기존 실행 검증은
유지하고, 경로별 정답·오승인·거절·토큰·지연을 모두 보고한다. 선택적 조건의 실제
응답 schema는 경로에 따라 다르므로 manifest를 case와 condition별로 봉인한다.

## 새 자료와 고정 절차

새 AI 자료 64문서·8개 family를 사용한다. 가족 01·05의 16문서를 개발 자료,
나머지 6개 가족의 48문서를 확인 자료로 사전 지정한다. 작업 원장·지원 대화·변경
로그·교대 메모의 네 문체에 국가·시점·scope 충돌, 직책·인용, 같은 표기의 다른
발생, 동음 약칭을 포함한다. 속성이 여러 문장이나 줄에 나뉘거나 일부 속성이
명시되지 않은 정상 연결도 평가한다. 특정 검사에 필요한 원문이 없다는 이유로
그 사례를 정답에서 제외하지 않는다.

소스와 라벨을 resolver·모델 출력 전에 작성하고 다른 AI 검토자가 64건 전체의
정의·라벨·core/full span·근거를 검토한다. 기존 fixture와 이름이 겹치는지 확인하고
소스·중복 검사·검토 문서를 해시로 고정한다. 모델 출력 뒤 데이터·정책을 고치면
해당 확인 자료는 노출된 진단으로 전환한다. 개발과 확인의 event·document·family
연결을 보존하며 같은 사건이 양쪽에 걸치면 거절한다.

자료가 새로 작성됐어도 AI 합성과 네 문체의 상관은 남는다. 실제 업무 모집단,
사람 gold 또는 독립 사건 64개의 감사로 부르지 않는다. 모델 사전 학습 오염이나
운영 위험을 소프트웨어 해시와 family 분할만으로 증명하지 않는다.

## 실행과 지표

Gemma 12B → Qwen 27B, 모델별 64×5=320회, **총 640회**다. temperature 0,
seed 0, thinking off, 단일 생성, 공통 출력 상한 768 tokens를 적용한다. 실제 두
모델 tokenizer로 입력과 예약 출력의 합이 8,192 tokens 이내인지 먼저 확인하고,
초과하면 원문을 잘라 맞추는 대신 준비 단계에서 실패한다. GPU는 다른 작업이
끝난 뒤 사용한다.

검증 전 의미 제안과 검증 후 승인을 분리한다. 주요 지표는 정답/오류 ID 제안,
올바른 승인·오승인·과잉 보류, schema·참조·근거 검사 실패, 전체 입력·출력 토큰과
요청 p50/p95/p99다. 선택적 조건은 경로별 수·선택 사유·비용·오류를 함께 제시한다.
family 단위 기술 통계와 개발/확인 결과를 분리하고, 같은 문서의 조건 비교나
모델 호출 수를 독립 표본 수로 세지 않는다.

원시 응답은 비공개로 보존하며 봉인된 요청과 원시 응답을 다시 파싱·재채점한
집계만 게시한다. 실제 업무 shadow 평가는 문서·용어집 입력 전까지
`WAITING_FOR_INPUT`이다.
